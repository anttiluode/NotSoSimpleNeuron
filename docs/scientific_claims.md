# Scientific claim boundaries

Current results support three narrow synthetic claims: spatially distributed scalar contacts can create distinct cable-state directions; ping timing can select receiver dynamics; and a local voltage-dependent branch mechanism can distinguish matched nearby versus crossed spatial patterns.

They do not establish biological eigenmode learning, a morphology advantage for frequency decoding, or a faithful receptor-level neuron model. In particular, the tuned point resonator is stronger than the single-site quasi-active cable on the frozen frequency selectivity metric.
