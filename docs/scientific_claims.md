# Scientific claim boundaries

Current results support four narrow synthetic claims: spatially distributed scalar contacts can create distinct cable-state directions; ping timing can select receiver dynamics; a local voltage-dependent branch mechanism can distinguish matched nearby versus crossed spatial patterns; and the current linear/quasi-active branch bank is exactly equivalent to an equal-dimensional modal realization.

The modal-boundary gate closes the linear morphology question for the current model. An orthogonal similarity transform gives a 48-state modal system with maximum transfer error **4.56e-15** across 81 tested frequencies and maximum cross-mode ratio **4.53e-16**. No parameters are fitted. Therefore the current cable morphology has **no unique linear expressivity** relative to its exact modal realization.

The active boundary is different. With active gain set to zero, the passive cable eigenbasis remains effectively diagonal (cross-mode ratio **2.30e-11**). With the local voltage-dependent mechanism engaged near its gate, the same basis has cross-mode ratio **0.582296**. Changing only resident voltage state rotates the locally linearized effective Jacobian by **34.3168 degrees**, with relative Jacobian change **1.16429**.

That establishes where the fixed-LTI collapse stops being globally valid in this synthetic system: local state-dependent spatial interaction couples modes and changes the local effective operator.

It does **not** establish biological eigenmode learning, a morphology advantage for frequency decoding, a faithful receptor-level neuron model, or a unique nonlinear advantage over every non-morphological system. A sufficiently rich nonlinear point/state-space model may reproduce the same state-conditioned family. The next honest comparison must therefore match nonlinear attackers on state and learnable-parameter budgets.
